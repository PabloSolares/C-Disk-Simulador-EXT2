
# C++Disk — Simulador de sistema de archivos EXT2

Sistema académico para simular la administración de discos, particiones y sistemas de archivos EXT2 mediante una API desarrollada en C++ y una interfaz web en React.

## Funcionalidades principales

- Creación y eliminación de discos virtuales.
- Administración de particiones.
- Montaje de discos.
- Formateo de particiones.
- Simulación de estructuras EXT2.
- Gestión de usuarios y permisos.
- Operaciones sobre archivos y directorios.
- Terminal de comandos.
- Explorador visual del sistema de archivos.
- Bitácora de operaciones.
- Comunicación entre frontend y backend mediante API REST.

## Tecnologías

- C++17
- Crow
- REST API
- React
- Vite
- JavaScript
- CORS
- Archivos binarios

## Estructura

```text
backend/    # Servidor y lógica del sistema de archivos
frontend/   # Interfaz web React
```

## Instalación
Consulta el manual técnico para los requisitos específicos del backend.
Frontend:
``` bash
cd frontend
npm install
npm run dev
```

El backend debe ejecutarse siguiendo las instrucciones de compilación incluidas en la documentación.
